# 决策记录：暂不引入自动 CD

日期：2026-10-01。

## 当前方案

GitHub Actions 负责测试、构建和推送 Docker Hub 镜像。CI 默认发布 amd64/arm64 双架构镜像，本机先拉取指定 SHA 版本联调；管理员在 ECS 拉取同一 SHA 版本，通过 Docker Compose 执行迁移、更新和健康检查。操作见[部署指南](../deployment.md)。

## 调整原因

曾尝试自行实现定时轮询、版本状态、自动回退、配置快照和邮件告警，但维护成本超过当前项目所需。对应脚本、测试、安装包及自动发布标记已移除，未安装到 ECS。

## 保留与后续建议

保留 GitHub CI、Dockerfile、生产 Compose 和必要的初始化、迁移及测试工具。以后若发布频率和协作规模确实需要自动 CD，再优先评估成熟平台或复用团队已有流水线；数据库兼容性与恢复始终独立管理。
