# 小程序原生能力扩展设计

日期：2026-09-28

本设计延续团队内部复制的单实例全栈模板。小程序使用 Taro React，首版只运行于微信；NestJS、Prisma、PostgreSQL 和 OSS 保持现有边界。目标是让复制项目的业务代码快速调用常用原生能力，同时能从目录判断其他微信能力的接入条件。业务数据由复制后的业务模块管理，通用能力不替业务保存位置、扫码或媒体内容。

## 范围与交付顺序

本次交付一份**按功能域覆盖的能力目录**，以及第一批可调用、可演示的原生模块。目录列出功能域、代表接口、当前状态、所需微信权限或硬件条件、业务接入点和官方文档链接；它不是逐条重抄 Taro 的全部 API。状态采用“已内置”“本批新增”“按场景接入”“平台或资质受限”四类。至少覆盖应用与导航、登录和用户授权、支付、分享与订阅、位置与地图、扫码、图片音视频、文件与存储、剪贴板、网络与设备、传感器与硬件、系统交互及行业专用接口。

第一批实现位置、扫码、媒体选择与预览、剪贴板、设备和网络状态。订阅消息发送、蓝牙、NFC、音视频通话、持续或后台定位及行业专用接口保留在目录中，按业务需求分别设计和实施。首批不新增后端路由、数据库表或第三方服务凭证；现有 OSS 图片上传仍由原模块负责。

选择按能力模块封装的方案。每个模块只处理该能力的参数、结果和失败状态，直接依赖 Taro；不创建可以动态调用任意微信 API 的统一桥接层，也不让演示页成为业务复用的唯一实现。这样复制项目能移除演示页并保留能力模块。

## 能力模块契约

`apps/miniapp/src/core/native` 下按位置、扫码、媒体、剪贴板、设备与网络拆分文件。模块返回可判断的成功值，或把用户取消、拒绝授权、当前环境不可用、实际调用失败区分为稳定状态；页面据此显示对应提示。只在用户发起的动作中请求敏感能力，不在启动、页面加载或后台静默获取。原始微信错误文案不进入公共契约、日志或埋点。页面可记录受控的能力名称和结果状态，不记录经纬度、地址、扫码内容、剪贴板内容、媒体路径或设备标识。

### 位置与地图

- `getCurrentLocation` 一次获取 GCJ-02 经纬度及接口返回的精度；不启用高精度强制定位、持续监听或后台定位。
- `chooseLocation` 打开微信地图让用户选点，返回名称、地址和 GCJ-02 经纬度；业务如需逆地理解析，须在复制项目中自行接入并处理其服务凭证。
- `openLocation` 仅对有效的 GCJ-02 经纬度调用微信地图，页面可展示上一步获得的位置。
- 坐标只保留在能力中心当前页面状态。拒绝授权时提供说明和用户主动打开设置的入口；取消选点不覆盖上一次成功结果。小程序配置声明位置用途，具体隐私描述由复制项目按实际场景填写和在微信平台配置。

### 扫码、媒体与剪贴板

- 扫码支持二维码和常见条码，返回码类型和文本内容；能力中心把结果作为普通文本显示，不自动打开 URL、跳转小程序路径或执行内容。
- 媒体由用户选择图片或视频，返回本地临时文件及类型、大小等可用元数据，并在页面预览。选中的文件不自动上传。需要持久保存图片时调用现有 OSS 图片模块；视频上传不属于本批。
- 剪贴板仅在用户点击“读取”或“写入”后调用系统接口；读取结果只显示在当前页面，写入内容来自用户输入。两者都不写入服务端或埋点。

### 设备与网络

- 设备模块只提供界面适配和诊断所需的非唯一信息，如平台、窗口尺寸和安全区域；不提供可用于跟踪用户的设备标识。
- 网络模块读取当前连接类型和连接状态；能力中心显示变化时才注册网络监听，离开页面时注销，避免跨页面残留监听。
- 模拟器不支持的能力明确显示不可用，不把模拟器结果当作真机验收。

## 页面与接入

门户保留现有精选卡片和像素风视觉，只新增“能力中心”入口。能力中心是一个按位置、扫码、媒体、剪贴板、设备与网络分区的页面；每项操作有明确按钮，结果和错误只显示在对应分区。位置区显示坐标系、纬度、经度和精度，并提供“地图选点”和“打开位置”；其他分区显示必要的结果摘要。页面不展示原始错误对象或敏感调试数据。

能力中心属于模板演示页面，复制项目可替换门户或移除该页；业务直接导入 `core/native` 中需要的模块。目录同时说明微信端可用性和未来其他端的差异，不承诺所有 Taro 平台都有同等能力。现有登录、资料、文件、分享和支付入口保持原有行为。

## 验证与上线边界

模块测试使用可替换的 Taro 调用，验证成功结果、用户取消、授权拒绝、环境不支持、调用失败及坐标范围等关键分支；网络监听测试确认离页注销。页面不为静态样式写镜像测试，改用微信开发者工具检查分区布局、按钮与结果反馈。运行小程序测试、类型检查和微信构建，并核对构建包仍满足微信主包大小限制。后端不变，因此不新增数据库或 API 测试。

开发者工具可验证路由、文案、剪贴板、网络状态和模拟定位流程。真实定位精度、系统权限弹窗、地图选点、相机扫码与媒体权限仍需真机逐项验收；文档把这些列为上线前检查，不将模拟器成功描述为真机验证。没有相关微信权限或隐私声明时，页面应给出可理解的失败状态，而不是要求团队加入空凭证。
